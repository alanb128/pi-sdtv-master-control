# The digital clock/audio monitor

The integrated clock/audio monitor is based on a Pi Pico 2 and a SparkFun audio amp board.

LED module: https://www.amazon.com/dp/B0B1PTB7MK

Amp: Unfortunately the ["Noisy Cricket"](https://www.sparkfun.com/sparkfun-noisy-cricket-stereo-amplifier-1-5w.html) has been discontinued, but other similar boards exist.

Speaker: https://www.amazon.com/dp/B0F2T7N93X
