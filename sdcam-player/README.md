#SDCAM deck

<img src="gh-sd-cam.jpg">

The player is reminiscent of a VTR crossed with a modern XDCAM deck. It plays back videos from SD cards in standard definition.

Computer: Pi 3b+
Display: https://www.adafruit.com/product/2088
OS: BalenaOS

Add custom configuration: `BALENA_HOST_CONFIG_dtoverlay` = "spi0-0cs" for the display
